二次根式定义

  • 形如 √a (a ≥ 0) 的式子
  • 两个条件：① 根指数为2 ② 被开方数 ≥ 0
  • 例：√2、√5、√0 是二次根式
  • ∛2（立方根）不是二次根式

有意义的条件

  • 被开方数 ≥ 0
  • 多个根式：每个都要满足
  • 含分母：分母 ≠ 0
  • 含零次幂：底数 ≠ 0
  • 含负指数幂：底数 ≠ 0
  • 取所有条件的交集

双重非负性

  • 对于 √a，必有：
  • ① a ≥ 0（被开方数非负）
  • ② √a ≥ 0（结果非负）
  • 应用：非负项之和=0 → 每项=0
  • 常见非负项：|A|、A²、√A

重要公式

  • ① (√a)² = a (a ≥ 0)
  • ② √a² = |a|
  • ③ (∛a)³ = a
  • ④ ∛a³ = a
  • ⑤ ⁿ√aⁿ = |a|(n偶) 或 a(n奇)

数轴化简

  • 根据数轴判断符号
  • √(x)² = |x|
  • x > 0 → |x| = x
  • x < 0 → |x| = -x
  • 注意：-x 当 x<0 时是正数！
