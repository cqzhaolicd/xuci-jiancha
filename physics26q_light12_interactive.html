📊 平均速度（轻课第1讲）

  • **平均速度 = 总路程 ÷ 总时间**（绝不是速度的平均值！）
  • 例：前 1/3 路程 4m/s、后 2/3 路程 7m/s → v̄ = 3s ÷ (s/4 + 2s/7) = 5.6 m/s
  • 陷阱：直接取 (4+7)/2 = 5.5 是错的

🧭 相对运动与参照物

  • "甲看到楼房上升" → 甲在下降（反向判断）
  • "乙看到甲上升" → 乙下降得比甲快（v乙 > v甲）
  • 口诀：看别人相对自己往哪动，自己就往反方向动得更多/更少

🫀 心电图 = 匀速运动 + 周期

  • 心动周期 T = 60 s ÷ 心率；走纸速度 v = 相邻波峰间距 ÷ T
  • 本题：A 间距 35mm、心率 60 次/min（T=1s）→ v = 35 mm/s
  • B 间距 30mm → T = 30/35 s → 心率 = 60 ÷ (30/35) = 70 次/min

🔫 "旋转法"测子弹速度

  • 塑片转速 n 转/s → 转一周时间 = 1/n；转 θ 角时间 = θ/(360n)
  • 子弹穿过间距 d 的两片塑片，时间 = 转过角所需时间
  • 转过 N 周零 60°：t = N/n + 1/(6n) → v = 6nd/(6N+1)

🛑 制动与警示牌（可见距离修正）

  • S反应 = v·t反应；S制动 = v²/(2a)；S总 = S反应 + S制动
  • 最短制动时间 t = v/a
  • ⚠️ 若只能看清前方 L 处的物体，警示牌需放在车后 S总 − L 处

🚸 横穿马路的两个临界

  • 快速临界（车刚到、人已过）：S人 = D/2 + d/2 + 车/人自身长度，S车 = S
  • 慢速临界（人刚到、车已过）：S人 = D/2 − d/2，S车 = S + l
  • 安全：比快速临界更快 或 比慢速临界更慢；相撞在两者之间

🔊 回声测距通用模型（第2讲）

  • 核心方程：声音路程 = 车路程 + 2×车与障碍物的距离差
  • 鸣笛时距障碍 x、听到回声时车走了 s：x + (x − s) = v声 × t
  • 变速时用平均速度算车走的路程

📡 超声波测速仪

  • 两次发出间隔 Δt，两次接收间隔 Δt′：Δt′ > Δt → 车在远离；Δt′ < Δt → 车在靠近
  • 汽车位置 = 声速 × 单程时间 ÷ 2
  • 车移动距离 ÷ 两次反射的时间间隔 = 车速

🧊 冰上声呐（分层介质）

  • 水深 h = v水·t₁/2（t₁ 为从水面发射到返回的时间）
  • 穿过冰层 + 水层：2H/v冰 + 2h/v水 = t₂ → H = v冰(t₂ − t₁)/2
  • 注意声在冰、水中的速度不同，时间要分段计算

🐭 传送带上的相对运动

  • 对地速度 = 相对带速度 ± 带速（同向相加、反向相减）
  • 例：鼠相对带 0.4 向 A，带 0.1 向 B → 对地 0.3 m/s（向 A）
  • 带面被污染长度 = 老鼠相对带面爬过的距离 = 0.4 × 时间
