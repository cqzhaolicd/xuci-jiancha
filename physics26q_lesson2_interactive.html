第二讲 · 相对速度与过街安全

🧭 相对速度解题两法

  • 口诀：以谁为参照物就把谁看作静止
  • 法① 换参考系（换参）：先求相对速度 V相对，再 t = S相对 / V相对
  • 法② 距离关系：用位移等式列方程（与换参结果一致）

🤝 相遇（相向运动）

  • 换参：V相对 = v₁ + v₂
  • 时间：t = S / (v₁ + v₂)
  • 距离关系：S₁ + S₂ = S → v₁t + v₂t = S

🏃 追及（同向运动）

  • 换参：V相对 = v₁ − v₂（v₁ > v₂）
  • 时间：t = S / (v₁ − v₂)
  • 距离关系：S₁ = S₂ + S → v₁t = v₂t + S

🚗 超车（同向，注意车身长度）

  • 相对距离：S相对 = l_A + l_B（两车长之和）
  • 相对速度：V相对 = v_A − v_B
  • 时间：t = (l_A + l_B) / (v_A − v_B)

🚙 错车（相向，注意车身长度）

  • 相对距离：S相对 = l_A + l_B
  • 相对速度：V相对 = v_A + v_B（相向相加）
  • 时间：t = (l_A + l_B) / (v_A + v_B)

⛵ 流水行船

  • 以地面为参照：顺水 V船′ = V船 + V水；逆水 V船′ = V船 − V水
  • 以水为参照：V相对 = V船（与水速无关）

🛑 刹车问题：过程分析（B卷压轴）

  • 反应阶段：发现危险后汽车仍以原速匀速行驶 → S反应 = v·t反应
  • 制动阶段：踩刹车后匀减速到停止 → S制动（题给）
  • 总停车距离：S总 = S反应 + S制动
  • v-t 图：水平段（反应）+ 斜向下直线（制动）

🚸 安全过街：行人两个临界

  • ① 快速临界（车刚到，人已过）：S人 = D/2 + d/2，S车 = S
  • ② 慢速临界（人刚到，车已过）：S人 = D/2 − d/2，S车 = S + l
  • 两临界都满足 t人 = t车（同时刻到达）
  • D 路宽 / d 人宽 / l 车长 / S 车到横道距离

🚲 安全过街：自行车版

  • ① 快速临界：S自 = D/2 + d/2 + C（多一个车身长 C）
  • ② 慢速临界：S自 = D/2 − d/2
  • ⚠️ 自行车起步/通过更慢，临界速度更小，更要注意“慢速临界”那一侧

📏 安全范围与相撞范围（看清问什么！）

  • 安全范围：比快速临界更快，或比慢速临界更慢
  • 相撞范围：慢速临界 < v < 快速临界
  • 口诀：要么人很慢，要么人很快

🎯 本讲方法论（老师强调）

  • 关键是整个过程的分析 + 临界状态的确定
  • 物理综合计算的通用逻辑：过程分析 + 临界状态分析
  • 临界 = 恰好通过 / 恰好相遇 → 用 t 相等或位移关系列等式

⚠️ 本讲易错提醒

  • 超车/错车忘记加车身长度（S相对 = l_A + l_B）
  • 相向用加法、同向用减法（相对速度方向搞反）
  • 刹车题漏掉反应距离（只算制动距离）
  • 过街题把快速临界与慢速临界弄反，或范围写成开闭不当

🎙️ 课堂要点 · 第二讲（运动学拔高二 · B卷压轴）

本讲核心：① 相对速度五题型——相遇（v₁+v₂）、追及（v₁−v₂）、超车与错车（相对距离 = l_A+l_B）、流水行船（顺加逆减）；两法：换参考系 / 距离关系。② 刹车问题——反应阶段（原速匀速）+ 制动阶段（匀减速），S总 = S反应 + S制动，看 v-t 图。③ 安全过街（B7 压轴）——快速临界（人已过：D/2+d/2，车走 S）与慢速临界（人刚到：D/2−d/2，车走 S+l），自行车快速临界再加车身长 C。

范围判断（最关键）：安全 = 比快速临界更快，或比慢速临界更慢；相撞 = 慢速临界 < v < 快速临界。口诀：要么人很慢，要么人很快。

🎓 老师强调的方法论：关键是整个过程的分析与临界状态的确定——初中物理后面所有综合计算都是同一逻辑：过程分析 + 临界状态分析。这是月考和半期压轴常考题型。
