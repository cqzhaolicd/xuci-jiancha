第6章 反比例函数

北师大九上 · 第6章 · 16 题 · 10 知识 · 10 卡 · 5 错

反比例函数的概念

一般地，形如 y=k/x（k 为常数，且 k≠0）的函数叫做反比例函数，其中 x 是自变量，y 是 x 的函数，等价形式为 xy=k。自变量 x 的取值范围是 x≠0 的一切实数，函数值 y 也不为 0。判断一个函数是不是反比例函数，关键看能否化成“常数除以 x”的形式：y=k/(x+1)、y=k/x² 都不是反比例函数。

待定系数法求表达式

求反比例函数表达式只需求出 k。若图象（或一组对应值）经过点 (x₀, y₀)，由 xy=k 得 k=x₀y₀。例：反比例函数的图象过点 (2,6)，则 k=2×6=12，表达式为 y=12/x。再任取图象上一点代入 y=12/x 检验，结果一致。

图象：双曲线与所在象限

反比例函数的图象由分别位于两个象限内的两支曲线组成，称为双曲线。k>0 时，两支曲线分别位于第一、三象限；k<0 时，分别位于第二、四象限。两支曲线向 x 轴、y 轴无限延伸、不断靠近，但永远不与坐标轴相交（因为 x≠0 且 y≠0）。

增减性：必须说“在每个象限内”

k>0 时，在每一个象限内，y 随 x 的增大而减小；k<0 时，在每一个象限内，y 随 x 的增大而增大。双曲线的两支在 x=0 处断开、不连续，所以不能说“在整个图象上 y 随 x 的增大而减小（或增大）”。例如 y=2/x 中，x 从 -2 增大到 3 时，y 从 -1 变为 2/3，反而增大了。比较两点函数值的大小，最稳妥的方法是代入横坐标求出 y 再比较。

图象的对称性

双曲线的两支关于原点成中心对称：若点 (x,y) 在图象上，则点 (-x,-y) 也在图象上。图象还关于直线 y=x 和 y=-x 成轴对称。由两支永不相交坐标轴可知，反比例函数图象与 x 轴、y 轴都没有交点。

|k| 的几何意义

过双曲线上任意一点 P(x,y) 分别作 x 轴、y 轴的垂线，两条垂线与坐标轴围成的矩形面积等于 |k|，即 S=|xy|=|k|；连接 P 与原点，所得三角形的面积等于 |k|/2。矩形面积给出的是 |k|：若面积为 6 且图象在第一、三象限，则 k=6，表达式为 y=6/x；若图象在第二、四象限，则 k=-6。

比较函数值大小的两条途径

① 代入计算（最保险）：点 A(-1,y₁)、B(-2,y₂) 在 y=2/x 的图象上，y₁=2/(-1)=-2，y₂=2/(-2)=-1，因为 -2<-1，所以 y₁0、一个 x<0）时不能用增减性，必须代入计算。

反比例函数的应用：建模与自变量范围

当两个量的乘积为定值时，它们成反比例关系，可建立 y=k/x 模型：面积一定的矩形，长×宽=S，长=S/宽，长与宽成反比；路程一定的行程，速度×时间=s，v=s/t，速度与时间成反比；总价一定时，单价与数量成反比。实际问题还要根据实际意义限定自变量的取值范围（如宽>0、时间>0），图象只取相应的一支或一段。

与一次函数综合

求反比例函数图象与一次函数图象的交点：把 y=k/x 代入 y=mx+b，整理成关于 x 的一元二次方程，解出横坐标再代回求纵坐标；方程实数根的个数即两图象交点的个数（0、1 或 2 个）。判断两图象“能否共存”：双曲线所在象限由 k 的符号决定，直线经过的象限由 m、b 决定，两者不矛盾即可共存。

常见变形与快速判断

反比例函数可写成 y=k/x 与 xy=k 两种等价形式，其中 x 的指数为 -1。y=3/x 是反比例函数（k=3）；xy=-5 也是（k=-5）；y=x/3 是正比例函数，不是反比例函数；y=3/(x+1)（分母不是单独的 x）、y=3/x²（x 的次数不是 -1）也都不是反比例函数。y 与 x 成反比，等价于 x 与 y 的乘积保持不变。
