第九讲 · 二元一次方程组（二）

二元一次方程组

  • 含两个未知数的两个一次方程组成
  • 一般形式：ax+by=c; dx+ey=f
  • 公共解 = 方程组的解
  • 解集：一对 x、y 值同时满足两式

代入消元法

  • ①选系数简单的方程变形
  • ②y=ax+b 代入另一方程消元
  • ③解一元一次方程求 x
  • ④代回求 y → 写出解

加减消元法

  • ①乘适当数使某未知数系数相反/相等
  • ②两方程相加/相减消元
  • ③解一元一次方程求一个未知数
  • ④代回求另一个 → 写出解

三元一次方程组

  • 三个方程、三个未知数
  • 方法：消元降次 → 二元 → 一元
  • 常用：代入 + 加减组合消元
  • 注意检验解的合理性

列方程解应用题

  • 审题 → 设元（选两个未知量）
  • 找两个等量关系
  • 列方程组 → 解方程组
  • ⚠️ 检验是否符合实际意义

等量关系常见类型

  • 总和：x+y=总人数/总件数
  • 倍数：2x-y=18（2倍多18）
  • 盈亏：每份×份数±余/缺=总量
  • 古代题：绳长/井深、鸡兔同笼
代入消元法：3x+4y=19; x-y=4
↑ 代入消元：用一个未知数表示另一个 → 代入消元 → 解一元一次方程
加减消元法：x+2y=1; 3x-2y=11
↑ 加减消元：让某未知数系数相反/相等 → 相加或相减消去

🎙️ 课堂要点 · 第九讲

二元一次方程组 — 两个未知数、两个一次方程，公共解是方程组的解；核心思想：消元，化二元为一元
代入消元法 — 选系数简单的方程，用一个未知数表示另一个（y=ax+b），代入另一方程消元；适用：某未知数系数为 1 或 -1
加减消元法 — 乘适当数使某未知数系数相反/相等，两方程相加或相减直接消元；适用：系数成倍数或相等
三元一次方程组 — 三个方程三个未知数，先消元成二元，再消元成一元；注意检验
列方程组解应用题六步 — 审题→设元→找两个等量关系→列方程组→解方程组→检验作答
古代数学题 — 《孙子算经》木长/鸡兔同笼、《算法统宗》分银/井深绳长/开店：抓住"每份×份数±余缺=总量"列式
💬 金句："二元要消元，代入看系数，加减看相反；列方程找等量，两个关系两个式。"
💬 金句："每份乘份数，余加缺来减；绳长井深分银开店，全是同一个模型。"
