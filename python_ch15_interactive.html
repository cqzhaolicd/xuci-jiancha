matplotlib 基础

import matplotlib.pyplot as plt; fig, ax = plt.subplots(); ax.plot(squares) 折线图; plt.show() 显示。fig=整个图, ax=子图。

plot() 易错点

只给 plot() 一个序列时假设 x=0 开始; 数据起点 x=1 要显式传 input_values: ax.plot(input_values, squares)。

图表定制

ax.set_title/set_xlabel/set_ylabel; ax.tick_params(labelsize=14); linewidth 控制线宽; plt.style.use('seaborn') 内置样式。

scatter() 散点

ax.scatter(2, 4, s=200) 画点, s=点大小。传两个等长列表配对成点: ax.scatter(x_values, y_values, s=10)。

colormap 颜色映射

强调数据模式: ax.scatter(x, y, c=y_values, cmap=plt.cm.Blues, s=10)。注意 c 不是 color(c 关联值序列, color 是单一颜色)。

savefig 保存

plt.savefig('squares_plot.png', bbox_inches='tight') 自动保存; bbox_inches='tight' 裁掉多余空白。

RandomWalk 随机漫步

纯随机决策的路径。random.choice() 做决策: 方向×距离=步长; x_step==0 且 y_step==0 时 continue 跳过(拒绝原地踏步)。

set_aspect('equal')

默认 Matplotlib 独立缩放两轴会把漫步拉伸; set_aspect('equal') 保持形状真实。

漫步美化

按顺序着色(c=point_numbers + cmap=Blues + edgecolors='none'); 绿点起点红点终点(必须在 plt.show() 之前); 隐藏坐标轴; 增大点数 RandomWalk(50_000)。

Plotly Express

交互式浏览器图表。pip install plotly pandas。px.bar(x=..., y=...) 两行出图, fig.show() 渲染 HTML 文件。

Die 类模拟骰子

random.randint(1, num_sides) 返回 1 到面数之间随机整数。双骰子 max_result = die_1.num_sides + die_2.num_sides 通用计算。

px.bar 直方图

title 参数加标题, labels 字典定制轴标签; fig.update_layout(xaxis_dtick=1) 每根柱子都有刻度; fig.write_html() 保存 HTML。
