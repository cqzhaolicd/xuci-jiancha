第2课作业解析 · 游大林寺序

📜 《游大林寺序》背景

  • 作者：白居易（字乐天），唐·元和十二年四月九日作于庐山
  • 文体：序（游记类序文，记游览与感慨）
  • 大林寺：庐山名寺，山高地深、气候偏冷——桃花比山下开得迟
  • 名句（白居易《大林寺桃花》）：“人间四月芳菲尽，山寺桃花始盛开。长恨春归无觅处，不知转入此中来。”

🧭 文本脉络（三段）

  • 第一段：交代游踪——与十七人自遗爱草堂出发，历东、西二林，抵化城，憩峰顶，登香炉峰，宿大林寺（大林穷远、人迹罕到）
  • 第二段：写景抒情——山高地深、时节绝晚；梨桃始华、涧草犹短；初到恍然若别造一世界→惊喜
  • 第三段：感慨议论——“迨今垂二十年，寂寥无继者。嗟乎，名利之诱人也如此！”→惋惜感叹

🔤 重点实词（一）

  • 凡十有七人：总共（不是“凡人”）
  • 穷远：穷 = 极、非常（副词，修饰形容词“远”）→ 极其偏远
  • 环寺：环绕；寺中惟板屋木器：只有
  • 其僧皆海东人：那些（僧人）

🔤 重点实词（二）

  • 时节绝晚：绝 = 极、非常；晚 = 迟、慢（季节变换得迟）
  • 梨桃始华：华 = 开花（盛开）（通“花”）
  • 涧草犹短：仍然；造：到、往（“别造一世界”= 另进入一个世界）
  • 迨今垂二十年：迨 = 等到；垂 = 将近

⚠️ 古今异义与固定搭配

  • 人物风候：人与气候（“人物”古今异义，非“人物形象”）
  • 口号：信口吟成（随口吟诵，不是“喊口号”）
  • 既而：不久（时间副词，固定搭配）
  • 聚落：村庄；山门：佛寺的大门；曾无半日程：还（竟）

✍️ 翻译题答题规范

  • ① 重点实词要“组词”落实（如 环=环绕、苍=苍绿/深青、瘦=细瘦）
  • ② 句意通顺完整，不能逐字硬抄
  • ③ 采分点：关键词翻译各 0.5 分 + 句子通顺 1 分
  • ④ 翻译后回读检查：是否补充了主语、语序是否顺畅

🎯 情感分析题的答题结构（第4题）

  • 第一步：先总述情感变化（由喜悦转为感叹惋惜）
  • 第二步：结合具体句子分点分析（“结合具体句子”= 必须引用原句或翻译原句）
  • 喜悦（2分）：引用“初到，恍然若别造一世界者”或“长恨春归无觅处，不知转入此中来”
  • 惋惜（2分）：引用“迨今垂二十年，寂寥无继者。嗟乎，名利之诱人也如此！”

🔍 由上下文推断词义

  • 遇到不确定的词 → 往后文/前后文找线索
  • 例：“时节绝晚”的“晚”——由下文“梨桃始华、涧草犹短”（花期晚）推知 = 迟、慢
  • 例：“大林穷远”的“穷”——“穷”修饰形容词“远” → 只能是副词（极、非常），不能译成“贫穷”
  • 方法：看搭配、看结构、看语境

📝 作业四题概览（本讲）

  • 第1题 解释加点词（4分）：华／造／既而／迨
  • 第2题 翻译句子（4分）：①环寺多清流苍石，短松瘦竹 ②山高地深，时节绝晚
  • 第3题 概括轨迹 + 游人少的原因（4分）
  • 第4题 结合句子分析情感变化（4分）

📚 实词积累法（若琳笔记本）

  • 按篇目+字头整理：《司马穰苴执法》《李密传》《白居易传》
  • 例：《司马穰苴执法》——既（已经）、素（向来）、乃（才）、谢（道歉）、期（约定）
  • 例：《李密传》——徒（只）、阴（暗地里）、俟（等待）、衔（怀恨）、拜（授予）、旋（旋即）
  • 例：《白居易传》——先（祖先）、多（称赞）、持（忍受）、与（到）、币（聘礼）
  • 同时归纳人物形象：敏慧过人／爱民如子／直言敢谏／忧国忧民

🎙️ 作业解析要点 · 第2课（《游大林寺序》）

文本梳理：白居易《游大林寺序》（元和十二年，庐山）。第一段交代游踪（遗爱草堂→东、西二林→化城→憩峰顶→登香炉峰→宿大林寺；大林穷远）；第二段写景抒情（山高地深、时节绝晚、梨桃始华→初到恍然若别造一世界→惊喜）；第三段感慨议论（迨今垂二十年寂寥无继者，名利之诱人也如此→惋惜）。

实词要点：华=开花｜造=到、往（进入）｜既而=不久｜迨=等到｜垂=将近｜曾=还｜穷=极、非常（副词）｜绝=极、非常｜晚=迟、慢｜因=于是｜口号=信口吟成｜人物风候=人与气候（古今异义）。

答题方法：① 翻译题——重点实词组词落实 + 句子通顺；② 情感分析题——先总述变化，再“结合文中具体句子”分点分析（必须引用原句，这一步不能丢）；③ 概括题——回原文定位、引用原句（送分题）。
