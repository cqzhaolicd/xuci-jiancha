第二讲 · 勾股定理复习进阶

📐 模块一：展开图求最短路径

  • 方法：把立体图形表面展开成平面，再用勾股定理求两点间线段长
  • 长方体：最短路径按不同展开方式分别计算，取最小值
  • 长方体体对角线：√(a²+b²+c²)
  • 圆柱：展开后横向长为半周长 πr（π取3 时 = 3r），纵向为高 h

🍶 吸管类：范围问题

  • 长方体 6×8×24、吸管 30cm：体对角线 = √(36+64+576) = 26
  • 插入最深 = 体对角线 26 → amin = 30−26 = 4
  • 插入最浅 = 高 24 → amax = 30−24 = 6
  • 所以 4 ≤ a ≤ 6（圆杯类同理：√(高²+底面直径²)）

🌳 绕树/绕柱：藤条与丝带

  • 树高 14m、底面周长 4m、绕 7 圈 → 展开后底 = 4×7 = 28，高 14
  • 藤长 = √(28²+14²) = √980 = 14√5
  • 核心：绕 n 圈 → 展开后横向长 = 周长 × n

🧗 圆柱蚂蚁：两条路线比较

  • 高 12、底面直径 6（r=3，π取3）：路线一 A→C→B = 12+6 = 18
  • 路线二（侧面展开）：√(12² + (πr)²) = √(144+81) = 15
  • 两路线相等：h + 2r = √(h²+9r²) → 4hr = 5r² → h/r = 5/4

🟦 模块二：勾股定理面积相关

  • 直角边上正方形面积和 = 斜边上正方形面积（a²+b²=c² 的面积化）
  • 四边形 DAB=BCD=90°，S₁+S₄=35、S₃=9 → S₂ = 26
  • （对角线 BD 分成两个直角三角形：S₁+S₃ = S₂+S₄）
  • 三边为直径作半圆：S₁ + S₂ = S₃（相似图形面积同规律）

🌲 勾股树与生长类

  • 边长 1 的正方形每次“生长”总面积 +1
  • 生长 2025 次 → 所有正方形面积和 = 2026
  • 逐次作垂线：OP₁=√2，OP₂=√3，…，OPn = √(n+1) → OP₂₀₂₅ = √2026

🔢 完美勾股数与偶差勾股数

  • 完美勾股数：a² + n² = (n+1)² → a² = 2n+1（a 必为奇数）
  • n<41：a² <83 → a = 3,5,7,9 → 4 组
  • n<1013：a² <2027 → a 为奇数 3~45 → 22 组
  • 偶差勾股数组（c²−b²=2）：(6,8,10) m=24、(8,15,17)… m₁ = 24，m₁₈ = 840

✏️ 模块三：设元求解

  • 核心：设所求（或最短）线段为 x，在不同直角三角形中列勾股方程
  • 两笔筒 8cm、12cm，铅笔露出 4cm、2cm → 铅笔长 23cm
  • 芦苇（池边长 10 尺、中央高出 1 尺）：设水深 x → x²+5² = (x+1)² → x=12 → 芦长 13 尺
  • 折叠类：折叠前后对应边相等（AB=AF、BE=EF）

🔁 折叠与翻折：经典题型

  • 长方形 AB=5、AD=3，沿 AE 折叠使 B 落在 CD 上 F：AF = AB = 5 → DF = 4、FC = 1
  • 设 BE = x，则 EF = x、EC = 3−x → x² = 1²+(3−x)² → x = 5/3
  • 关键：找到含未知数的直角三角形列方程

📊 模块四：B卷综合

  • 数形结合：网格中构造三角形，用两边之和 > 第三边比较无理数大小（√5+1 > √10）
  • √(x²+…)+√((…−x)²+…) 型最小值 → 转化两点间距离 + 将军饮马（对称 + 直线）
  • 圆柱吸管 25cm（直径 10、高 12）：a ∈ [25−2√61, 13]

📐 模块五：解三角形（可解性）

  • 核心：作高把斜三角形转化为直角三角形求解
  • ⚠️ 钝角三角形的高可能在三角形外部（必须分类讨论）
  • 特殊角边比：30°→1:√3:2；45°→1:1:√2；60°→1:√3:2
  • 已知 AB=12、AC=10、BC 边高 6：BD=6√3、CD=8 → BC = 6√3+8 或 6√3−8

⚠️ 本讲六大易错点

  • 不区分斜边与直角边，盲目套公式（最长边才可能是斜边）
  • 题目无图形时遗漏多种情况，缺分类讨论
  • 混淆勾股定理与逆定理：定理由直角得边，逆定理由边判定直角
  • 立体图形展开方式选错，最值算错
  • 勾股树不会转化面积关系
  • 解斜三角形作高时忽略高在外部的钝角情形

🎙️ 课堂要点 · 第二讲（勾股定理复习进阶）

本讲核心（五大模块）：① 展开图求最短路径（立体表面展开 + 勾股，取最小）；② 勾股定理面积相关（正方形/半圆/勾股树面积转化）；③ 设元求解（设 x 列勾股方程，折叠类用对应边相等）；④ B卷综合（数形结合、将军饮马、偶差勾股数组）；⑤ 解三角形（作高转化，注意钝角高在外部）。

易错点（教师强调）：① 不区分斜边与直角边，盲目套公式（最长边才可能是斜边）；② 题目无图形时遗漏多种情况，缺分类讨论；③ 混淆勾股定理和逆定理；④ 立体图形展开方式选错；⑤ 勾股树不会转化面积关系；⑥ 解斜三角形作高时忽略高在三角形外部的情形。

教师寄语：勾股定理是平面几何核心工具——现阶段支撑几何计算；九年级学解直角三角形、圆、相似三角形、二次函数几何综合题频繁用到；也为高中平面解析几何两点间距离公式、立体几何空间距离计算奠基。
