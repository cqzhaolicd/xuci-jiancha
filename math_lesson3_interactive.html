同类二次根式
📌 定义

同类二次根式：几个二次根式化为最简二次根式后，如果被开方数相同，则它们是同类二次根式。

✅ 示例
√8 = 2√2 与 √18 = 3√2 → 被开方数都是2 → 同类二次根式
📝 合并同类二次根式

与合并同类项类似：系数相加减，根式不变

1
化简 — 每个根式化为最简二次根式
2
判断 — 看被开方数是否相同
3
合并 — 系数相加减，根式不变
✅ 示例
2√3 + 5√3 = (2+5)√3 = 7√3
√12 + √27 - √48 = 2√3 + 3√3 - 4√3 = √3
✏️ 练习 · 判断是否同类
下列各组根式中，是同类二次根式的是？ A. √2 和 √3 B. √8 和 √18 C. √12 和 √20
B
√8=2√2, √18=3√2 → 被开方数都是2，是同类
A: √2 和 √3 被开方数不同
C: √12=2√3, √20=2√5 → 被开方数不同
模块一：分母有理化
📐 有理化的基本方法
1
平方有理化（单项根式）：(√a)² = a
2
平方差有理化（和差根式）：(√a+√b)(√a-√b) = a-b
注：(√a+√b)² = a+b+2√ab，若 √ab 为有理数，完全平方也可以实现有理化。
📐 分母有理化方法
①单项根式：同乘以分母本身
1/√a = √a / a
②和差根式：同乘以使分母构​​成平方差公式的因式
1/(√a+√b) = (√a-√b)/(a-b)
1/(√a-√b) = (√a+√b)/(a-b)
例题1 · 分母有理化化简
1/(1+√2) = ? 1/(1+√3) = ? 1/(2+√3) = ? (3√2-2√3)/(3√5-4√3) = ?
= √2-1
= 2-√3
= (3-√6)/3
= -3√10 - 4√6 + 2√15 + 8
例题2 · 综合计算
(1) √((√5-3)²) + 2/(√5+2) + (π-2025)⁰
解：原式 = 3-√5 + 2(√5-2) + 1 = √5
例题2 · 比大小
比较：√2020 - √2019 ___ √2019 - √2018
方法：利用 √a - √b = (a-b)/(√a+√b)
√2020-√2019 = 1/(√2020+√2019)
√2019-√2018 = 1/(√2019+√2018)
∵ √2020+√2019 > √2019+√2018
∴ √2020-√2019 < √2019-√2018
模块二：二次根式裂项
🔑 核心裂项公式

1/(√n + √(n+1)) = √(n+1) - √n

1/(√n + √(n+2)) = (√(n+2) - √n) / 2

望远镜求和：中间项全部抵消，只剩首尾两项
例题3 · 裂项求和
1/(1+√2) + 1/(√2+√3) + 1/(√3+√4) + ... + 1/(√2024+√2025)
原式 = (√2-1)+(√3-√2)+(√4-√3)+...+(√2025-√2024)
= √2025 - 1
= 45 - 1 = 44
例题3 · 间距为2的裂项
1/(1+√3) + 1/(√3+√5) + 1/(√5+√7) + ... + 1/(√99+√101)
原式 = (√3-1 + √5-√3 + √7-√5 + ... + √101-√99)/2
= (√101 - 1)/2
例题3 · 较复杂裂项
1/(2√1+√2) + 1/(3√2+2√3) + 1/(4√3+3√4) + ... + 1/(100√99+99√100)
通项公式：1/[(n+1)√n + n√(n+1)] = √n/n - √(n+1)/(n+1)
原式 = 1 - √2/2 + √2/2 - √3/3 + ... + √99/99 - √100/100
= 1 - √100/100 = 1 - 10/100 = 9/10
模块四：共轭二次根式 · 根式知二推二
💡 核心方法

已知 x+y 和 xy，可求：

  • x² + y² = (x+y)² - 2xy
  • (x-y)² = (x+y)² - 4xy
  • x³ + y³ = (x+y)(x² - xy + y²)
  • x/y + y/x = (x²+y²)/(xy)
关键：先分母有理化化简 x、y，再算 x+y 和 xy
例题4 · 共轭求值
(1) 已知 x=√6+1, y=√6-1，求 x²+y²+xy
x+y=2√6, xy=5
x²+y²+xy = (x+y)² - xy = 24-5 = 19
例题4 · 共轭求值
(2) 已知 x=1/(2+√3), y=1/(2-√3)， 求 ① (x+y)/(x-y) ② x²-3xy+y²
先分母有理化：x=2-√3, y=2+√3
x+y=4, x-y=-2√3, xy=1
① (x+y)/(x-y) = 4/(-2√3) = -2√3/3
② x²-3xy+y² = (x-y)² - xy = 12-1 = 11
例题4 · 带根号求值
(3) 已知 x+y=2√3, xy=-2，求 x³y+2x²y²+xy³
原式 = xy(x²+2xy+y²) = xy(x+y)²
= -2 × (2√3)² = -2 × 12 = -24
例题4 · 双重二次根式
(4) 已知 a+b=√(√2025+√2024), a-b=√(√2025-√2024)，求 a⁴-b⁴
(a+b)(a-b)=√((√2025+√2024)(√2025-√2024))=√1=1
∴ a²-b²=1
(a+b)²+(a-b)²=2√2025, ∴ a²+b²=√2025=45
a⁴-b⁴ = (a²+b²)(a²-b²) = 45 × 1 = 45
练习 · 分母有理化+共轭综合
x = (√3-√2)/(√3+√2) y = (√3+√2)/(√3-√2) 求 √(xy)+(x+y)² / √(xy)-(x+y)²
x = 5-2√6, y = 5+2√6
x+y=10, xy=1
原式 = (1+100)/(1-100) = -101/99
