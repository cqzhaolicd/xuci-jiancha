📌 二次根式降次

  • 已知 x = √a + √b，求 x²、x³ 的高次表达式
  • 核心：先求 x²，再逐步降次
  • 关键是构造 x² = a + b + 2√ab
  • 高次多项式代入时，先化简再求值
  • 例：a = (√3-1)/(√3+1) → 先有理化再降次
  • 必考题型，七下期末考试高频出现

🔷 二次根式配方

  • 形如 a ± 2√b → 配成 (√m ± √n)²
  • 关键：找两个数 m、n，使 m+n=a，mn=b
  • 例：5+2√6 = (√2+√3)²
  • 例：7-4√3 = (2-√3)²
  • 注意完全平方后的开方结果取正
  • 配方法是双重根号化简的基础

🔄 双重二次根式

  • 形如 √(a ± √b)，内层是根号
  • 先将 a ± √b 配方成 (√m ± √n)²
  • 再整体开方：√(√m ± √n)² = √m ± √n
  • 本质就是配方，照猫画虎学规律
  • 例：√(17-12√2) = √((3-2√2)²) = 3-2√2
  • 注意内层配方的形式要正确

🧩 复杂双重根式

  • 多重嵌套：√(a ± √(b ± √c))
  • 从内向外逐层配方
  • 每层配成完全平方式后开方
  • 例：√(6-√(17-12√2))
  • → 先内层：√(17-12√2)=3-2√2
  • → 再外层：√(6-(3-2√2))=√(3+2√2)=√2+1

📊 代数式求值技巧

  • 先化简要代入的表达式（有理化/配方）
  • 利用 x+1/x 型的对称式简化计算
  • 高次多项式：先用低次表示高次（降次）
  • 例：m=2015/(√2016-1)，先有理化
  • → m = √2016+1，再代入高次表达式
  • 先化简，再代入 是核心原则
