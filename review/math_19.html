数学 · 第19题

无理数的整数部分与小数部分 · 分母有理化

来源：2026-09-21 ｜ 赵若琳学习中心 · 复习模块

题目

19. 已知 x = 3 − √3，a、b 分别是 x 的整数部分和小数部分，则 x + 1/a + 1/b = ______。 【参考答案】6（若琳答对）

五维分析

A　已知条件

① x = 3 − √3； ② a 是 x 的整数部分，b 是 x 的小数部分； ③ 求 x + 1/a + 1/b 的值。

B　求解什么

求 x + 1/a + 1/b 的值。

C　做题思路

① 先估范围定整数部分：1 < √3 < 2 ⇒ 1 < 3 − √3 < 2 ⇒ x 的整数部分 a = 1； ② 小数部分 = 原数 − 整数部分 ⇒ b = (3 − √3) − 1 = 2 − √3； ③ 分母有理化求 1/b： 1/(2 − √3) = (2 + √3)/[(2 − √3)(2 + √3)] = (2 + √3)/(4 − 3) = 2 + √3； ④ 整体代入： x + 1/a + 1/b = (3 − √3) + 1/1 + (2 + √3) = 3 − √3 + 1 + 2 + √3 = 6。 （−√3 与 +√3 恰好抵消，得到整数——这正是本题的设计点。）

D　易错点

① 把小数部分误当成“√3 那一部分”：小数部分必须是「原数 − 整数部分」，本题 b = 2 − √3； ② 整数部分判断错：√3 ≈ 1.732 ⇒ 3 − √3 ≈ 1.268 ⇒ 整数部分是 1（不是 2）； ③ 有理化时符号或公式写错：(2 − √3)(2 + √3) = 4 − 3 = 1； ④ 漏掉 1/a（a = 1 ⇒ 1/a = 1 这一项）； ⑤ 结果应化简到整数 6，若留下含根号的式子说明某一步没抵消对。

E　知识点

① 无理数的整数部分与小数部分（估值法：a ≤ x < a+1）； ② 分母有理化：利用平方差公式 (a+b)(a−b) = a² − b²； ③ 二次根式的加减与化简； ④ 整体代入、先化简再求值的思想。
