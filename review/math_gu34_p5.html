数学 · 第5题（中线折叠·BH）

直角三角形中线翻折 · 对称点与距离计算

来源：2026-09-25 ｜ 赵若琳学习中心 · 复习模块

题目

（2025秋·金牛区校级期中）在 Rt△ABC 中，∠ACB = 90°，AC = 6，BC = 8，CG 是 AB 边上的中线，将 △ACG 沿 CG 翻折后得到 △HCG，连接 BH，则 BH 的长为 ______。 【出处】第二讲 勾股定理综合复习 第5题（红笔判错）

五维分析

A　已知条件

① Rt△ABC，∠ACB = 90°；② AC = 6，BC = 8；③ CG 是 AB 边上的中线（G 是 AB 中点）；④ 将 △ACG 沿 CG 翻折得 △HCG。

B　求解什么

求 BH 的长。（若琳写 √39，红笔判错；正确答案 14/5 = 2.8）

C　做题思路

【第一步：先算基本量】 AB = √(AC² + BC²) = √(6² + 8²) = 10 ⇒ 中线 CG = AG = BG = 5（直角三角形斜边中线等于斜边一半）。 【第二步：翻折给出 H 的位置】 H 是 A 关于直线 CG 的对称点 ⇒ CH = CA = 6，HG = AG = 5。 【第三步：算 BH —— 用坐标最稳】 以 C 为原点：A(6, 0)，B(0, 8)，则 G = AB 中点 = (3, 4)； 直线 CG：y = (4/3)x，即 4x − 3y = 0； A(6, 0) 关于该直线的对称点（用点到直线距离公式求对称点）： H = (−42/25, 144/25) 〔验证：HG = 5 ✔，CH = 6 ✔〕 于是 BH² = (0 + 42/25)² + (8 − 144/25)² = (42/25)² + (56/25)² = (1764 + 3136)/625 = 4900/625 = 196/25； ⇒ 「BH = 14/5 = 2.8」。 （也可用面积法/三角形中线长公式间接求解，但坐标法最不容易出错。）

D　易错点

① 把 G 当成「CG 的中点」而不是「AB 的中点」（CG 是中线，G 在 AB 上）； ② 误以为 H 落在 BG 上而用 BH = BG − GH 或勾股硬减（方向不对）； ③ 忘记「斜边中线 = 斜边一半」这条性质，算不出 CG = 5； ④ 翻折后没有利用 CH = CA、HG = GA 这两条不变量； ⑤ 若琳写 √39 —— 属于「凭感觉拼凑」（64 − 25 = 39），既没用到 6、8，也得不出正确长度。

E　知识点

① 勾股定理求斜边（6-8-10）； ② 直角三角形斜边中线性质（CG = ½AB）； ③ 轴对称的性质（对应线段相等）； ④ 坐标系中求一点关于一条直线的对称点； ⑤ 两点间距离公式 + 二次根式化简（4900/625 = 196/25）。 📌 出处：第二讲 勾股定理综合复习 第5题。同页第3、4题见上条与同页说明。
