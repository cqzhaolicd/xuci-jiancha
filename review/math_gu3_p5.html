数学 · 题目5（偶差勾股数组）

勾股数通项推导 · 数列规律与求和

来源：2026-09-25 ｜ 赵若琳学习中心 · 复习模块

题目

（2025秋·成华区校级期中）定义：若三个正整数 a、b、c 满足 a < b，a² + b² = c²，且 c − b = 2，则称 (a, b, c) 为“偶差”勾股数组。例如：(6, 8, 10)、(8, 15, 17) 都是“偶差”勾股数组。令 m = a + b + c，将 m 从小到大排列，分别记为 m₁、m₂、m₃、…、mₙ（n 为正整数），则 m₁ 的值为 ______；m₁₈ 的值为 ______。 【出处】第二讲 勾股定理综合复习 题目5（两空均被红笔判错）

五维分析

A　已知条件

① a、b、c 为正整数；② a < b；③ a² + b² = c²；④ c − b = 2；⑤ m = a + b + c，从小到大排成 m₁、m₂、…

B　求解什么

求 m₁ 和 m₁₈。（若琳答 m₁ = 24、m₁₈ = 3012，两空均判错；按定义推导 m₁ = 24、m₁₈ = 840）

C　做题思路

【第一步：把「偶差」条件化成通项】 ① 由 c − b = 2 得 c = b + 2； ② 代入 a² + b² = c²：a² + b² = (b+2)² = b² + 4b + 4 ⇒ 「a² = 4b + 4」 ⇒ a² 是 4 的倍数 ⇒ a 是「偶数」； ③ 设 a = 2k（k 为正整数）⇒ b = (4k² − 4)/4 = 「k² − 1」，c = 「k² + 1」； ④ 由 a < b 得 2k < k² − 1 ⇒ k² − 2k − 1 > 0 ⇒ 「k ≥ 3」； 验证：k = 3 ⇒ (6, 8, 10) ✔；k = 4 ⇒ (8, 15, 17) ✔ 与题目例子一致。 【第二步：求 m 的表达式】 m = a + b + c = 2k + (k² − 1) + (k² + 1) = 「2k² + 2k = 2k(k + 1)」 （k ≥ 3 时 m 随 k 单调递增） 【第三步：代入】 ① k = 3 ⇒ m₁ = 2 × 3 × 4 = 「24」； ② 第 18 个对应 k = 3 + (18 − 1) = 20 ⇒ m₁₈ = 2 × 20 × 21 = 「840」。

D　易错点

① 不会由 c − b = 2 推出「a 必为偶数」这一步（这是整题的钥匙）； ② 忘记 a = 2k 之后还要用 a < b 限制 k ≥ 3（若允许 k = 2 会出现 (4, 3, 5)，a > b 不合定义）； ③ 把「从小到大排列的序号」与 k 的取值搞混（第 18 个 ⇒ k = 20，不是 k = 18）； ④ 若琳 m₁ 填 24（与推导一致）但被判错 —— 建议与老师核对 m₁ 的标准答案；m₁₈ 填 3012 明显是按错误规律（误差极大）算出的。

E　知识点

① 勾股数的通项推导（a = 2k, b = k²−1, c = k²+1）； ② 由等式变形 + 整除性判断字母取值范围（偶数性）； ③ 不等式约束（a < b ⇒ k ≥ 3）； ④ 数列的单调性与序号对应（第 n 项 ⇔ k = n + 2）； ⑤ 代数式化简（m = 2k(k+1)）。 📌 出处：第二讲 勾股定理综合复习 题目5。同页另有两题（芦苇长度 13 ✔、△ABC 面积 130/126/66）见下条。
