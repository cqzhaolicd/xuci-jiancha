数学 · 第5题（数形结合求最值）

数形结合 · 网格作图比较大小 + 距离和最值（将军饮马）

来源：2026-09-25 ｜ 赵若琳学习中心 · 复习模块

题目

（2025秋·双流区校级期中）“数形结合”是一种重要的数学思想方法……在正方形网格中构造某些图形可以发现和解决一些数学问题。所有网格均是正方形网格，每个小正方形边长均为 1，点 A、B、C 都在格点上。 （1）如图1，AB 的长度为 ______，△ABC 中 AB 边上的高的长度为 ______。 （2）如图2，在正方形网格中构造 △ABC，可以比较 √5 + 1 与 √10 的大小，理由如下：因为点 A、B、C 都为小正方形的顶点（构造图形），所以 AB + BC > AC（三角形任意两边之和大于第三边）。因为 AB = √(1²+2²) = √5，AC = √(1²+3²) = √10（勾股定理），BC = 1，所以 √5 + 1 > √10。请你参考例子中的方法，在图3中构造图形，比较 2√2 + 2 与 2√5 的大小，并说明理由。 （3）请运用上面“数形结合”的数学思想方法，求 √(x²+9) + √((x−15)²+25) 的最小值。 【出处】第二讲 勾股定理综合复习 第5题（此页有红笔叉）

五维分析

A　已知条件

① 正方形网格，每小格边长 1，A、B、C 均在格点； ② 已知示例：AB = √5、AC = √10、BC = 1 ⇒ √5 + 1 > √10； ③ 第（3）问要求按同样的数形结合思想求最小值。

B　求解什么

（1）AB 的长与 AB 边上的高；（2）用网格作图比较 2√2 + 2 与 2√5 的大小并说明理由；（3）求 √(x²+9) + √((x−15)²+25) 的最小值。

C　做题思路

【（2）思路】把每条二次根式看成格点间线段长： 2√2 + 2 = √8 + 2，2√5 = √20；在网格中构造一个三角形，使两边分别等于 √8 = 2√2（横 2 竖 2 的斜边）与 2，第三边等于 2√5 = √20（横 2 竖 4 的斜边），由「三角形两边之和大于第三边」得 2√2 + 2 > 2√5。 【（3）核心：把根式「翻译」成两点间距离，再用将军饮马求最值】 ① 取点 P(x, 0) 在 x 轴上； ② √(x² + 9) = √(x² + 3²) = P 到点 A(0, 3) 的距离； ③ √((x−15)² + 25) = √((x−15)² + 5²) = P 到点 B(15, 5) 的距离； ④ 于是原式 = PA + PB，求其最小值； ⑤ 作 A(0, 3) 关于 x 轴的对称点 A′(0, −3)：PA = PA′ ⇒ PA + PB = PA′ + PB ≥ A′B（两点之间线段最短）； ⑥ 当 P 是 A′B 与 x 轴的交点（x = 45/8）时取最小值： A′B = √((15−0)² + (5−(−3))²) = √(15² + 8²) = √(225 + 64) = √289 = 17。 ⇒ 最小值为 17。

D　易错点

① 看到 √(x²+9) 想不到它是一次函数图像上的「两点距离」（左边 = 3，右边 = 5 就是两段高度）； ② 不会把两个根式拆成两段距离 PA + PB（不会「构造图形」）； ③ 求 PA + PB 最小值时不知道作对称点（将军饮马模型）； ④ 对称点取错轴（应作关于 x 轴 —— 即 P 所在直线的对称），或计算时把 15² + 8² 写成 15² + 5²； ⑤ 第（2）问只给结论不写「两边之和大于第三边」的理由（本题明确要求说明理由）。

E　知识点

① 数形结合思想（代数式 ⇄ 图形）； ② 勾股定理及其逆用（把 √(a²+b²) 看成直角三角形的斜边）； ③ 三角形三边关系（两边之和大于第三边）比较大小； ④ 两点间距离公式的几何意义； ⑤ 轴对称求最短路径（将军饮马模型）； ⑥ 二次根式的化简（√289 = 17）。 📌 出处：第二讲 勾股定理综合复习 第 5 题。此页有红笔叉（第(3)问未掌握），正确最小值 17；第(1)问答案需按图1网格核对（可由面积法 高 = 2S/AB 反推）。
