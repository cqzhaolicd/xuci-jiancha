第六讲 · 勾股定理应用

展开图求最短路径

  • 立体图形 → 展开成平面
  • 两点之间线段最短
  • 构造直角三角形 → 勾股定理
  • ⚠️ 核心思想：化立体为平面

圆柱最短路径

  • 圆柱侧面展开 = 长方形
  • 底边 = 底面周长（不是直径！）
  • AB = √(高² + 周长²)
  • 例：高6、周长16 → √(36+256)=√292

长方体最短路径

  • 三种展开：主+左 / 主+俯 / 左+俯
  • 分别求三种路径长度
  • 取最小值为最短路程
  • 例：8×2×4 → √(8²+6²)=10

台阶与缠绕问题

  • 台阶：展开成平面折线
  • 水平 = 长，垂直 = 宽×级数+高×级数
  • 缠绕n圈：底边 = 周长×n
  • 彩带/细线/金属丝同类问题

台风/噪音问题·三步法

  • ① 作垂线：点到路径最短距离
  • ② 判影响：最短距离 vs 影响半径
  • ③ 算时间：影响路程÷速度
  • 影响路程 = 2×√(半径²-垂距²)

特殊角速算

  • 30°：1 : √3 : 2
  • 45°：1 : 1 : √2
  • 22.5°、15°：半角构造
  • 台风题常用：sin30°=½ 求垂距
圆柱侧面展开：最短路径 = 对角线
↑ 圆柱侧面展开成矩形：底边=底面周长C，高=h，最短路径为对角线 AB=√(h²+C²)
台风影响范围：作垂线 + 弦长
↑ 台风三步法：①过城市作垂线求最短距离d ②d<影响半径r则受影响 ③弦长=影响路程，时间=路程÷速度

🎙️ 课堂要点 · 第六讲

展开图求最短路径 — 圆柱：AB=√(高²+底面周长²)；长方体：三种展开取最小；正方体棱长1→√5；台阶：水平=长、垂直=宽×级数+高×级数
缠绕问题 — 彩带/细线绕n圈：底边=底面周长×n，再与高组成直角三角形
台风/噪音三步法 — ①作垂线求最短距离d ②d与影响半径r比较判影响 ③影响路程=2√(r²-d²)，时间=路程÷速度
勾股逆定理妙用 — 已知三边可用逆定理判直角（如30²+40²=50²），再求面积或垂线
特殊角速算 — 30°角对边=斜边一半（sin30°=½）；45°等腰直角：1:1:√2
风力衰减问题 — 12级-距离/25=当前风力；受4级以上影响→风力达4级处为影响边界
圆柱周长陷阱 — 展开图底边是底面周长（C=πd=2πr），不是直径！做题先看给的是半径还是周长
