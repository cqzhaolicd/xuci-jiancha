第八讲 · 勾股定理构造与翻折

构图法求最值

  • 数形结合：代数式 → 几何图形
  • √(x²+a²) = 直角边 x、a 的斜边
  • √((b-x)²+c²) = 直角边 b-x、c 的斜边
  • 最小值 = 两点间最短路径

最值公式

  • √(x²+a²)+√((b-x)²+c²) min
  • = √(b² + (a±c)²)
  • 水平距离 b，竖直差 a±c
  • 同侧相减、异侧相加

翻折性质

  • 折叠前后对称全等
  • 折痕 = 对称轴
  • 对应边、对应角相等
  • 折痕是夹角的平分线

翻折三步

  • ①抓不变量：找全等
  • ②设未知数：代数化
  • ③锁 Rt△：列勾股方程
  • ⚠️ 一定产生等腰/全等

折叠模型

  • 点落边上：△AEF 勾股
  • 点落顶点：△ABF / △AGE
  • 点落对角线：△CEF
  • 点落图形外：△BDF 等腰

构图法进阶

  • 赵爽弦图：全等直角三角形
  • 网格构图：√5、√10、√13 求面积
  • 平方配方：x²-2x+10 → (x-1)²+3²
  • 绝对值/根式 → 距离
构图法：√(x²+a²) + √((b-x)²+c²) 求最小值
↑ 两斜边之和 ≥ 折线 → 拉直最短：min = √(b² + (a±c)²)，同侧相减、异侧相加
矩形翻折：点落边上（折痕为 CF）
↑ 折叠后全等：对应边相等，锁定直角三角形列勾股方程（三步：标边→设x→列式）

🎙️ 课堂要点 · 第八讲

构图法求最值 — 核心：把 √(x²+a²) 看成直角边 x、a 的斜边，√((b-x)²+c²) 看成直角边 b-x、c 的斜边；求代数式最小值 = 求两点最短路径；min = √(b²+(a±c)²)
最值公式记忆 — 水平距离取 b，竖直边同侧相减、异侧相加；例 √(x²+16)+√((9-x)²+64) min = √(9²+12²) = 15
翻折本质 — 轴对称变换：折叠前后对称全等，折痕是对称轴，对应边/角相等
翻折三步 — ①抓不变量（找全等）②设未知数（代数化）③锁定直角三角形列勾股方程
折叠模型 — 点落边上/顶点/对角线/图形外四类，选对 Rt△ 是关键；图形外必产生等腰△BDF
构图进阶 — 赵爽弦图（全等Rt△拼接）、网格构图（√5/√10/√13 求面积）、平方配方（x²-2x+10 → (x-1)²+3²）
💬 金句："根式藏斜边，构图求最短；min 等于水平平方加竖差方。"
💬 金句："翻折全等定不变量，设 x 列勾股方程解线段。"
💬 金句："点落图形外，等腰 BDF 必现。"
