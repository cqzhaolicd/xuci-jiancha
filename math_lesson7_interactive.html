第七讲 · 勾股定理解三角形

特殊角三边比

  • 45°-45°-90°：1 : 1 : √2
  • 30°-60°-90°：1 : √3 : 2
  • 120°等腰：作高 → 30°直角三角形
  • ⚠️ 口诀：30°对半、45°等腰

解三角形定义

  • 已知3个边角元素求其它
  • 可解类型：SSS / SAS / AAS / ASA / HL
  • SSA 是陷阱：可能两解
  • 特殊角：30° 45° 60° 及补角 150° 135° 120°

解直角三角形

  • 勾股定理 a²+b²=c²
  • 特殊角比例：1:1:√2 / 1:√3:2
  • 30°对边 = 斜边×½
  • 45°斜边 = 直角边×√2

作高法（核心）

  • 斜三角形 → 作高 → 直角三角形
  • 保留特殊角，不破坏已知角
  • 钝角作外高（延长线）
  • 设未知数 → 列勾股方程

SSA 两解陷阱

  • 两边 + 非夹角 → 可能两解
  • 例：AC=4√2, ∠A=45°, BC=5 → AB=7 或 1
  • 高在三角形内（内高）或延长线（外高）
  • ⚠️ 无图题必须分类讨论

拓展公式

  • 海伦公式：S=√(s(s-a)(s-b)(s-c))
  • 中线定理：AB²+AC²=2(AD²+BD²)
  • 面积 S = ½·底·高（作高求高）
  • 等腰三角形作高 = 中线 = 角平分线
作高法：斜三角形 → 两个直角三角形
↑ 保留特殊角 60°/45° 作高 CD：△ACD 是 30-60-90，△BCD 是 45-45-90，分别用三边比求 AD、BD，相加得 AB
SSA 两解：AC=4√2, ∠A=45°, BC=5
↑ 同一条件可画出两个三角形：CD=4 为高，BD=√(5²-4²)=3 → AB=AD+BD=7 或 AB=AD-BD=1，两解都满足

🎙️ 课堂要点 · 第七讲

常见特殊角三边比例 — ①45°-45°-90°：1:1:√2 ②30°-60°-90°：1:√3:2，看到特殊角直接套比例，比硬算快得多
解三角形 — 已知3个边角元素（SSS/SAS/AAS/ASA），求其它元素；斜三角形通过作高转化为直角三角形求解
特殊角及补角 — 30° 45° 60° 及补角 150° 135° 120°：补角作高后回到 30°/45°/60° 的直角三角形
保留特殊角，作高线 — 作高时不破坏已知特殊角（从顶角向对边作垂线），钝角三角形作外高（延长线）
SSA 陷阱 — 两边一非夹角不能唯一确定三角形，可能两解，无图题必须分类讨论内高/外高
设未知数列方程 — 公共高 + 两个直角三角形 → 两个勾股方程 → 解出未知段（SSS 型求面积/高的通法）
💬 金句："30°对半，45°等腰，补角作外高，解三角靠勾股。"
💬 金句："特殊角先看，作高不拆角；SSA 要小心，两解别漏掉。"
💬 金句："设未知数列方程，公共高是桥梁。"
